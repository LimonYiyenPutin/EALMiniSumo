# EALMiniSumo

  🍋 Mini Sumo Oyunu
Python ve Pygame kullanılarak geliştirilmiş, arena dışına itmeli eğlenceli bir mini sumo oyunudur! Amaç, rakibinizi beyaz çember sınırlarının dışına iterek hayatta kalmak.

  🕹️ Kontroller
W / S: İleri ve Geri hareket
A / D veya Sol/Sağ Ok Tuşları: Karakteri döndürme
E: Vurara itmesi (Özel vuruş - Cooldown süresine dikkat!)
R: Oyunu yeniden başlatma (Kaybettiğinizde veya kazandığınızda)
ESC: Oyundan çıkış

  📊 HUD (Ekran Bilgileri)
Sol altta anlık olarak karakterinizin X/Y koordinatlarını, bakış açısını, merkeze olan uzaklığını ve özel vuruşunuzun Cooldown (bekleme süresi) durumunu takip edebilirsiniz.

  🚀 Kurulum ve Çalıştırma
Projeyi çalıştırmak için bilgisayarınızda Python ve Pygame kütüphanesinin yüklü olması gerekir.
Terminali veya komut satırını oyun klasörünün olduğu konuma açın.


!!!!!!!!!!!!!!!!!!!!!!!!!

Gerekli kütüphaneyi yükleyin (eğer yüklü değilse):
Power Shell'de çalıştırın:
	pip install pygame

Oyunu başlatmak için ana dosyayı çalıştırın:
	python main.py
